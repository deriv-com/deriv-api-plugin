# Contributing

Thanks for your interest in improving the Deriv API plugin.

The plugin is a thin client that points **Cursor** and **Claude Code** at a
hosted Deriv API MCP server and ships one Cursor rule. It holds no credentials
and runs no local server, so most contributions are to the documentation, the
manifests, or the Cursor rule.

## How to contribute

- **File an issue** for a bug, a documentation gap, or a proposed change.
  Include what you expected, what happened, and enough detail to reproduce it.
- **Open a pull request** against the `master` branch. Keep each pull request
  focused on a single change, and describe what it does and why.
- Match the existing style of the file you are editing, and update any
  documentation your change affects in the same pull request.

## Reporting a security issue

Please do not open a public issue for a suspected vulnerability. Follow the
private disclosure process in [`SECURITY.md`](SECURITY.md) instead.

## Maintainer

This plugin is maintained by **`@deriv_api_v2_team`**. Issues and pull requests
are triaged by that team; mention them if you need a review or a decision.
